# Emoji :rocket: and super/subscript

Ship it :rocket: :+1: :tada: — or :-1: if not. Adjacent :smile::smile: work too.
Unknown names stay text: :nope: :not_an_emoji_name: and so do times like 12:30:45 or 9:05.
Glued to words is not emoji: foo:rocket:bar, x:smile: and :smile:y.

Code is untouched: `:rocket:` and `x^2^` and `H~2~O`.

```
:rocket: in a fence
x^2^ H~2~O
```

Einstein: E = mc^2^, ordinal 1^st^, nested ^**bold**^ and a\^escaped^ caret.
Spaces break it: ^not super^ stays text; 2^10 alone is text; footnote-like [^a][^b] too.

Single tilde H~2~O is GFM strikethrough by default; ~~double~~ always is.
With spaces ~a b~ is also strikethrough here.
